# Wordpress-Carcassonne
Ce site a été réalisé dans le cadre d'une Situation d'Apprentissage et d'évaluation (SAÉ) en économie et en WEB pour l'IUT de Vannes. En aucun cas la ville de Carcassonne n'a été contactée ou n'a fourni d'informations. Ce site est réalisé sur Wordpress et a pour objectif d'attirer de nouveaux habitants dans la ville.
